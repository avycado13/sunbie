## Features
- 1 Inch Display
- 3 Sensors all communicating over I2C
- LSM6DS3 for IMU and motion detection
- BME280 for temperature and environment detection
- TSL25911FN for light detection that I will probably hook up to control screen brightness
- 2 Multicolor addressable LEDs (WS2812B)
- 5 Buttons
- Buzzer that can generate multiple pitches
- Testpoints for easy debugging
- Optional Battery Soldering point
- Powered by XIAO ESP32-C3
